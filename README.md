# Paraíso Nevado

Sitio web de una sola página hecho con [Astro](https://astro.build): carrusel de portada, galería, "Sobre nosotros", gastronomía (desayuno, almuerzo, merienda y cena), formulario de contacto con mapa, modo oscuro y nieve cayendo. Es 100 % estático, así que se publica en Vercel sin servidor.

## Compatibilidad

Pensado para móviles actuales y antiguos: se compila para iOS 12+ y Chrome 64+, el diseño evita funciones recientes de CSS, las imágenes tienen respaldo JPG, la nieve usa solo CSS (con menos copos en pantallas pequeñas y desactivada si la persona prefiere menos movimiento).
